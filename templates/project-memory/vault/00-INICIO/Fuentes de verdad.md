# Fuentes de verdad

## Prioridad

1. Código, pruebas y configuración vigente de `{{SOURCE_REPOSITORY}}`.
2. Documentación versionada del repositorio.
3. Decisiones aprobadas.
4. Notas verificadas de esta memoria.
5. Fuentes externas oficiales y versionadas.

## Contradicciones

Cuando dos fuentes discrepen:

1. Identificar las afirmaciones incompatibles.
2. Revisar la evidencia y sus fechas.
3. Usar el repositorio para describir el comportamiento actual.
4. No inventar la intención del diseño.
5. Proponer la corrección de la fuente desactualizada.

## Evidencia adecuada

- Ruta y símbolo del código.
- Prueba automatizada.
- Pull Request fusionado.
- Documento versionado.
- Decisión aprobada.
- Documentación oficial de una dependencia.

Una conversación o una rama sin integrar no representan por sí solas el estado vigente.
