# Recursos

## Propósito

Conservar diagramas, imágenes y archivos auxiliares que mejoren una explicación documental.

## Reglas

- Preferir formatos editables y accesibles.
- Añadir título, propósito, fuente y fecha.
- No guardar capturas con secretos o datos personales.
- No usar recursos visuales como única fuente de una regla técnica.
