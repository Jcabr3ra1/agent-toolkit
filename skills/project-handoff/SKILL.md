# Traspaso de proyecto

Produce un resumen que permita continuar sin reconstruir todo el contexto.

## Flujo

1. Identifica objetivo, alcance y estado real.
2. Comprueba cambios, rama, pruebas y artefactos relevantes cuando estén disponibles.
3. Separa completado, en curso, bloqueado y pendiente.
4. Registra decisiones confirmadas y preguntas abiertas.
5. Señala riesgos, archivos relevantes y el siguiente paso más pequeño.
6. Omite conversaciones, razonamientos internos, secretos y salidas extensas.

Usa [la plantilla de traspaso](references/handoff-template.md).

## Calidad mínima

- Cada afirmación importante debe poder rastrearse a evidencia.
- Un bloqueo debe indicar causa y qué lo desbloquea.
- Un pendiente debe tener condición de finalización.
- El siguiente agente no debe asumir que una prueba pasó si no se ejecutó.
